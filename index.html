HTTP Server Benchmark

Python, C, Go, Rust

Wrote the same HTTPS server four times, in Python, C, Go and Rust, ran it on a Raspberry Pi 5, and load-tested it with wrk at 10, 100 and 1,000 concurrent connections. Go, C and Rust all leveled off at about 56,500 requests per second, which works out to 99.4% of the Pi's 1 Gbps Ethernet. The bottleneck was the network hardware, not the code.
